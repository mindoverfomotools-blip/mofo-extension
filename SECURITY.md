# Security and bug bounty

## Report a problem

Email **mindoverfomotools@gmail.com** with "SECURITY" in the subject. Please don't open a public issue for a
security problem. We reply within 72 hours.

## Bounty: up to $1,000

We pay up to **$1,000** (in USDC) for the first report of a real problem in the published extension, such as a way
for MOFO, or someone abusing MOFO, to:

- move funds, start a trade, or sign anything
- read or leak wallet data, private keys, seed phrases, or the fomo.family session
- run code that isn't in this repository
- read or act on any website other than fomo.family
- send user data anywhere other than the servers listed in the README

The amount depends on how serious the problem is and is decided by us. Findings that need a modified copy of the
extension don't count; the problem has to exist in the version published on the Chrome Web Store.

## Not in scope

Daily limits, the quality of AI answers, prices or holder data, problems in fomo.family itself or in other
websites, and anything that needs physical access to your computer.

## Rules

- Test only with your own accounts and data.
- Give us 14 days to fix it before you talk about it publicly.
- One reward per problem, to the first person who reports it.
